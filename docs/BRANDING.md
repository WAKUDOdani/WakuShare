# WakuShare icon and wordmark

The current icon contains a large gradient ribbon W and a folded document on a transparent background. There is no surrounding tile or pair of arrows. The PNG master is in `build/icon-mark-source.png`. The earlier tile design is preserved in `build/icon-source.png` as a reference.

The built-in image_gen tool edited the earlier master with transparent output. No API key or separate image API client was used. Current prompt:

> Use case: precise-object-edit. Edit target: the supplied WakuShare icon. Create a Windows application icon consisting ONLY of the large folded ribbon W in the foreground and a single folded-corner document behind it. Remove the entire rounded-square tile, its neon rim, its dark fill, both arrows, and all external atmosphere. Preserve the recognizable thick soft ribbon W shape and glossy lavender/purple/magenta/blue gradient of the source. Make the W dominant, wide and bold, occupying almost the full width, with the folded document rising behind its upper-right area. Keep document visible and clearly recognizable, in deep blue-violet with bright lavender folded corner. Isolated sculptural mark on genuine transparent alpha, including gaps and space around the W/document silhouette. Compact centered square composition, tightly framed with narrow safe padding, optimized to read clearly at 24 and 32 pixels. Clean antialiasing, crisp strong silhouette, restrained highlights, minimal glow. No rounded background tile, no enclosing border, no arrows, no words, no extra shapes, no baked checkerboard. Output one finished icon.

Earlier tile extraction prompt, retained for provenance:

> Use case: background-extraction. Edit the supplied WakuShare app icon. Keep the central glossy rounded-square tile, its exact large rounded corners, purple/blue/pink neon rim, folded document, ribbon W and two opposing arrows, with the same composition and colors. Remove the entire external dark square canvas and the wide atmospheric glow/background outside the rounded tile. Outside the tile must be genuinely transparent alpha, including the corners. Keep the dark glossy interior of the rounded tile opaque. Make one clean square application icon asset, centered and tightly framed, occupying about 94-96% of its square canvas, with only narrow transparent padding. Sharp antialiased silhouette suitable for Windows ICO downsampling. No text, no checkerboard baked in, no added elements, no external background. Preserve the supplied design rather than redesigning it.

`pnpm icons` converts the master using Sharp. It measures visible bounds and creates PNG assets, a multi-size ICO, and an ICNS. Windows window/shell assets fill their canvas without extra outer padding. The ICO includes 16, 20, 24, 28, 32, 36, 40, 48, 60, 64, 72, 96, 128 and 256 px images for different display scales. App UI and ICNS retain their own small padding. Converted assets are checked into the repository, so ordinary application builds do not need image generation.

`BrandWordmark.tsx` renders WakuShare as text, with a pink, purple and blue CSS gradient on Share. Light and dark palettes preserve contrast. Forced-colors mode uses normal text color. The sidebar pairs a 24 px icon with the 21 px wordmark in one row, separated by an 8 px gap. The icon starts on the same left edge as the navigation icons using the same 12 px horizontal inset. The gap before navigation remains compact.

The Windows afterPack hook embeds the ICO and product/version metadata in the app executable. It checks that executable code sections and unrelated resources retain their hashes. No code-signing credentials are involved. Package verification checks the embedded icon against the source ICO and verifies installer hashes. These checks are distinct from signing or publishing a release.
