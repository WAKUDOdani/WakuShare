### WakuShare 1.2.0 - Preset transfer and a Russian interface

Move composition presets between CapCut libraries.

> [!NOTE]
> Archived release. For a regular installation, choose the [latest WakuShare version](https://github.com/WAKUDOdani/WakuShare/releases/latest).

### Download

| Edition                                                                                                                       | Purpose                         |
| ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| [**Windows x64 installer**](https://github.com/WAKUDOdani/WakuShare/releases/download/v1.2.0/WakuShare-1.2.0-setup-x64.exe)   | Regular app installation        |
| [**Windows x64 Portable**](https://github.com/WAKUDOdani/WakuShare/releases/download/v1.2.0/WakuShare-1.2.0-portable-x64.exe) | No installation; manual updates |

### What's new

- Import and export `.wakupresets` packages: a full selection, folders, or individual presets, including available source files.
- Choose a destination folder, merge folders with matching names, and review exact duplicates: skip, keep a separate copy, or replace with a backup.
- Check that CapCut is closed before importing presets, and launch it with a button after transfer.

### Interface

- English/Russian language switching, a new logo and gradient app name, and consistent dropdown controls.
- A "Stay in touch?" welcome dialog with a persistent "Don't show again" setting.

### Important

Composition presets are supported; Text_V2 and Adjust are not transferred. Fonts are collected from explicit references and are not installed in Windows automatically.

### Compatibility and technical details

Tested target: **CapCut International Windows 9.6.0.4097, x64**.

122 automated tests, TypeScript, ESLint, and package verification. The English/Russian interface and preset transfer in CapCut were also accepted for this release.

You only need one EXE. `Source code` contains the source; `latest.yml`, `.blockmap`, and runtime archives are not needed for normal use. Checksums are in `SHA256SUMS.txt` under Assets.

## Что нового

- Импорт и экспорт `.wakupresets`: целиком, по папкам или по отдельности, с доступными исходниками.
- Выбор папки назначения, объединение одноимённых папок и проверка полных дубликатов: пропуск, отдельная копия или замена с резервной копией.
- Проверка закрытия CapCut перед импортом пресетов и кнопка его запуска после переноса.

## Интерфейс

- Переключение EN/RU, новый логотип и градиентное название, единые выпадающие списки.
- Окно «Будем на связи?» при запуске с постоянной настройкой «Больше не показывать».

## Важно

Поддерживаются композиционные пресеты; Text_V2 и Adjust не переносятся. Шрифты собираются по явным ссылкам и автоматически в Windows не устанавливаются.
