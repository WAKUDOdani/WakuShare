# Как пользоваться WakuShare

[← На главную](../README.md) · [Скачать](https://github.com/WAKUDOdani/WakuShare/releases/latest) · [Документация](README.md)

WakuShare работает на Windows x64. Проверенная версия редактора - CapCut International 9.6.0.4097. Язык приложения можно изменить в **Настройки → Внешний вид → Язык интерфейса**.

## Перенести проект

1. На исходном компьютере открой **Проекты** и выбери проект CapCut.
2. Экспортируй его. Для наиболее полного пакета оставь включённым перенос кешей. Если приложение сообщает об отсутствующих ресурсах, сначала проверь предупреждения.
3. Передай полученный `.wakushare` на другой компьютер. Прежние `.capshare` тоже можно открыть.
4. В WakuShare выбери **Импорт**, перетащи файл или выбери его через диалог. Если проект с таким именем уже существует, для первой проверки используй отдельную копию.
5. Дождись завершения и открой проект в CapCut. Если он не появился в списке редактора, перезапусти CapCut.

Несколько временных шкал и вложенные композиции сохраняются. Исходники не перемещаются с прежнего места: в импортированном проекте они размещаются в `Resources/local/Исходники`, а ссылки обновляются на новые файлы. Независимые исходники с одинаковыми именами не объединяются.

Пакет не может восстановить файл, которого уже не было при экспорте. Системные шрифты, облачные и аккаунтные эффекты могут потребовать установки или повторного скачивания на другом компьютере.

## Перенести пресеты

Поддерживаются локальные **композиционные пресеты** CapCut. Пакет пресетов имеет расширение `.wakupresets`; Text_V2 и Adjust этим переносом не охватываются.

### Экспорт

1. Открой **Пресеты → Мои пресеты**. Если библиотека находится на другом диске, укажи её через **Выбрать библиотеку**.
2. Отметь отдельные пресеты или целые папки. Стрелка возле папки открывает её, галочка выбирает содержимое.
3. Нажми **Экспортировать выбранное** и сохрани пакет. При сообщении об отсутствующих исходниках укажи нужный файл либо исключи соответствующий пресет.

### Импорт

1. Закрой CapCut и выбери **Пресеты → Открыть пакет**.
2. Отметь нужные папки и пресеты, выбери библиотеку и папку назначения. При необходимости создай вложенную папку.
3. Выполни проверку импорта. Для подтверждённых полных дубликатов доступны пропуск, отдельная копия или замена выбранного пресета.
4. Проверь решения и начни импорт. Замены сохраняют резервную копию. Если пакет содержит активные ресурсы эффектов, подтверди доверие только к известному источнику.
5. После завершения запусти CapCut. Не удаляй перенесённые ресурсы библиотеки.

Файлы шрифтов собираются по явным доступным ссылкам. WakuShare не устанавливает системные шрифты автоматически. [Подробнее о переносе пресетов](PRESET_TRANSFER.md).

## Настроить автосинхронизацию

1. Открой **Проводник** и включи **Автосинхронизацию**.
2. Выбери область: **Все проекты** для общей медиатеки или **Этот проект** для текущего открытого проекта CapCut.
3. Нажми **Добавить папку**, выбери папку Windows и подтверди подключение.
4. Открой нужный проект в CapCut. Папка с вложенными каталогами появится прямо в корне медиатеки; дополнительная папка WakuShare не создаётся.
5. Дождись сообщения **«Импорт завершён - можно работать»**. При большом пакете на обработку самому CapCut потребуется время.

После первого импорта новые файлы и изменения обрабатываются по событиям. Постоянного сканирования каждые несколько секунд нет. Общие подключения применяются и к новым, и к существующим проектам при их открытии.

### Кнопки и состояния

| Элемент             | Назначение                                                                                           |
| ------------------- | ---------------------------------------------------------------------------------------------------- |
| **Показать папку**  | Открыть исходную папку в Windows                                                                     |
| **Сверить сейчас**  | Вне очереди сверить содержимое и добавить недостающие карточки; это не повторный импорт всего пакета |
| **Карандаш**        | Изменить название подключения в WakuShare                                                            |
| **Отсоединить**     | Убрать подключение из настроек синхронизации; исходные файлы не удаляются                            |
| **Тумблер папки**   | Приостановить или возобновить её синхронизацию                                                       |
| **Ожидание CapCut** | Открыть нужный проект либо восстановить доступность источников; подтверждённый прогресс сохраняется  |

Если результат предыдущей операции не удалось подтвердить, приложение не повторяет её вслепую. Не удаляй служебное состояние, чтобы принудительно запустить импорт заново; при остановке сохрани сообщение и сообщи об ошибке.

### Переименование, перенос и удаление

- Для файла, используемого на таймлайне, сначала выйди из проекта на главную CapCut: редактор может удерживать исходник. Затем переименуй или перенеси файл в Windows и снова открой проект.
- Переименование и перенос сохраняют идентичность материала. Копирование создаёт независимый источник.
- Название, заданное вручную внутри CapCut, не переименовывает файл Windows и сохраняется независимо от него.
- Если используемый исходник удалён с диска, оставшийся клип обрабатывает сам CapCut как потерянное медиа. WakuShare не подменяет его заглушкой.
- Удаление материала в CapCut может штатно удалить связанные клипы. Если исходник остался на диске, следующая сверка восстановит только карточку в медиатеке, не удалённые клипы.

## Закрытие приложения и обновления

При включённой синхронизации закрытие окна WakuShare оставляет его в системном трее. Для полного выхода используй команду выхода в меню значка рядом с часами.

**Установленная версия:** проверяет стабильные релизы этого репозитория, скачивает обновление и предлагает перезапуск. Начинай установку после окончания файловых операций.

**Portable:** проверка обновлений открывает [страницу последнего выпуска](https://github.com/WAKUDOdani/WakuShare/releases/latest). Скачай новый Portable EXE, полностью закрой прежний WakuShare через трей и используй новый файл. Portable означает запуск без установки, а не отдельное хранение всех настроек рядом с EXE; обычные сборки используют профиль WakuShare.

## Частые вопросы

### Что скачивать из Assets?

Для обычной установки - `WakuShare-<версия>-setup-x64.exe`. Для запуска без установки - `WakuShare-<версия>-portable-x64.exe`. Нужен один из них. `Source code` предназначен разработчикам, `latest.yml` и `.blockmap` обслуживают обновления. Runtime уже включён в приложение.

### Windows показывает предупреждение об издателе

Сборки пока не имеют цифровой подписи издателя. Скачивай приложение только из [официальных релизов WakuShare](https://github.com/WAKUDOdani/WakuShare/releases). Контрольные суммы опубликованы в `SHA256SUMS.txt`; совпадение хеша подтверждает байты файла, но не является подписью издателя.

### Почему нужно доверие к пакету эффектов?

Настоящие эффекты могут содержать Lua/JS и другие активные ресурсы. Подтверждение позволяет передать их CapCut; оно не обезвреживает код. Можно отменить импорт. Обычные медиа и автосинхронизация такого подтверждения не требуют. [Границы защиты](security-audit-2026-10-21.md).

### Работает ли другая версия CapCut?

Целевая проверенная сборка - CapCut International Windows 9.6.0.4097, x64. Для других версий нужна отдельная проверка. Зашифрованные проекты JianYing не поддерживаются.

### Как сообщить о проблеме?

Создай [Issue](https://github.com/WAKUDOdani/WakuShare/issues): укажи версии WakuShare и CapCut, действие и текст ошибки. Не публикуй личные проекты, исходники, пароли и полный конфиг. Вопросы о возможной уязвимости сначала обсуди с автором через [Telegram](https://t.me/WAKUDOdani), не прикладывая публичный вредоносный пакет.
