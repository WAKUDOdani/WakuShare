### WakuShare 1.1.1 - Interface and update fixes

Clearer attribution, version display, and update messages.

> [!NOTE]
> Archived release. For a regular installation, choose the [latest WakuShare version](https://github.com/WAKUDOdani/WakuShare/releases/latest).

### Download

| Edition                                                                                                                       | Purpose                         |
| ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| [**Windows x64 installer**](https://github.com/WAKUDOdani/WakuShare/releases/download/v1.1.1/WakuShare-1.1.1-setup-x64.exe)   | Regular app installation        |
| [**Windows x64 Portable**](https://github.com/WAKUDOdani/WakuShare/releases/download/v1.1.1/WakuShare-1.1.1-portable-x64.exe) | No installation; manual updates |

### Fixes

- The author label now reads WakuShare by WAKUDO Dani.
- The version number stays visible while checking for updates and after a network error.
- Removed an explanatory line in Settings; scrolling starts below the heading.
- An empty release feed shows a clear message instead of a technical parsing error.

### Important

An installed copy of 1.1.0 updates through Settings → Check for updates → Restart to update. Portable updates are manual.

### Compatibility and technical details

Tested target: **CapCut International Windows 9.6.0.4097, x64**.

80 automated tests, TypeScript, and ESLint. The project transfer core is unchanged.

You only need one EXE. `Source code` contains the source; `latest.yml`, `.blockmap`, and runtime archives are not needed for normal use. Checksums are in `SHA256SUMS.txt` under Assets.
