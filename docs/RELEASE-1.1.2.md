# WakuShare 1.1.2 - Обновления Portable

<details>
<summary><strong>English release notes</strong></summary>

### WakuShare 1.1.2 - Portable updates

Checking for updates in Portable opens the latest release page.

> [!NOTE]
> Archived release. For a regular installation, choose the [latest WakuShare version](https://github.com/WAKUDOdani/WakuShare/releases/latest).

### Download

| Edition                                                                                                                       | Purpose                         |
| ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| [**Windows x64 installer**](https://github.com/WAKUDOdani/WakuShare/releases/download/v1.1.2/WakuShare-1.1.2-setup-x64.exe)   | Regular app installation        |
| [**Windows x64 Portable**](https://github.com/WAKUDOdani/WakuShare/releases/download/v1.1.2/WakuShare-1.1.2-portable-x64.exe) | No installation; manual updates |

### Fixes

- The Portable edition's Check for updates button opens GitHub Releases so you can download the new EXE manually.
- An explanation appears below the version; the browser opens only when clicked. The installed edition keeps its download and Restart to update workflow.

### Important

Portable 1.1.0/1.1.1 users need to download the newer Portable version manually first. The button change is available starting with 1.1.2.

### Compatibility and technical details

Tested target: **CapCut International Windows 9.6.0.4097, x64**.

83 automated tests, TypeScript, and ESLint. The project transfer core is unchanged.

You only need one EXE. `Source code` contains the source; `latest.yml`, `.blockmap`, and runtime archives are not needed for normal use. Checksums are in `SHA256SUMS.txt` under Assets.
