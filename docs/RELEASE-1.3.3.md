# WakuShare 1.3.3

- Аккуратная кнопка Telegram внизу боковой панели: пресеты и находки для монтажа всегда под рукой.
- Световой блик на кнопке «Заглянуть в Telegram» в приветственном окне. Один проход при наведении; учитываются настройки уменьшения движения.
- Более заметный переключатель «Все проекты / Этот проект» в «Проводнике»: увеличены текст, размеры и отступы, улучшен контраст активной области. Кнопка «Добавить папку» выровнена по высоте.
- Портативная версия отмечается подписью `v1.3.3 · Portable` под названием приложения. Установленная версия показывает только номер.

Сохранены все возможности версии 1.3.2, включая автосинхронизацию папок, импорт старых `.capshare` и экспорт в `.wakushare`. Движок синхронизации не менялся.

Для установки — `WakuShare-1.3.3-setup-x64.exe`.
Для запуска без установки — `WakuShare-1.3.3-portable-x64.exe`.

Среды запуска и модуль синхронизации уже включены в обе сборки. При сборке из исходников используется прежний проверенный runtime, закреплённый в `runtime-lock.json`.
