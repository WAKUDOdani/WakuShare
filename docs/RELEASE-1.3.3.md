# WakuShare 1.3.3 - Telegram и удобная навигация

<details>
<summary><strong>English release notes</strong></summary>

### WakuShare 1.3.3 - Telegram and clearer navigation

Quick access to Telegram and more prominent navigation controls.

> [!NOTE]
> Archived release. For a regular installation, choose the [latest WakuShare version](https://github.com/WAKUDOdani/WakuShare/releases/latest).

### Download

| Edition                                                                                                                       | Purpose                         |
| ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| [**Windows x64 installer**](https://github.com/WAKUDOdani/WakuShare/releases/download/v1.3.3/WakuShare-1.3.3-setup-x64.exe)   | Regular app installation        |
| [**Windows x64 Portable**](https://github.com/WAKUDOdani/WakuShare/releases/download/v1.3.3/WakuShare-1.3.3-portable-x64.exe) | No installation; manual updates |

### What's new

- A Telegram card at the bottom of the sidebar for presets and editing finds.
- A single light sweep over the welcome dialog's Telegram button, respecting reduced motion preferences.

### Improvements

- Larger All projects / This project controls in Explorer, better contrast, and an Add folder button with matching height.
- The Portable edition displays `v1.3.3 · Portable`; the installed edition displays its version number.

### Important

The features from 1.3.2 remain: automatic sync, `.capshare` import, and `.wakushare` export. The sync engine is unchanged.

### Compatibility and technical details

Tested target: **CapCut International Windows 9.6.0.4097, x64**.

Both EXEs include the runtimes and sync worker. This version uses the previous base runtime pinned in runtime-lock.json.

You only need one EXE. `Source code` contains the source; `latest.yml`, `.blockmap`, and runtime archives are not needed for normal use. Checksums are in `SHA256SUMS.txt` under Assets.

## Что нового

- Карточка Telegram внизу боковой панели: пресеты и находки для монтажа.
- Один световой блик на кнопке Telegram в приветственном окне; учитывается уменьшение движения.

## Улучшения

- Увеличен переключатель «Все проекты / Этот проект» в «Проводнике», улучшен контраст и выровнена высота кнопки добавления папки.
- Портативная версия показывает подпись `v1.3.3 · Portable`; установленная - номер версии.

## Важно

Сохранены функции 1.3.2: автосинхронизация, импорт `.capshare` и экспорт `.wakushare`. Движок синхронизации не менялся.
