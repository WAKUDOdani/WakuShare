# WakuShare 1.3.3 - Telegram и удобная навигация

Быстрый доступ к Telegram и более заметные элементы навигации.

> [!NOTE]
> Архивный выпуск. Для обычной установки выбирай [последнюю версию WakuShare](https://github.com/WAKUDOdani/WakuShare/releases/latest).

## Скачать

| Вариант                                                                                                                       | Назначение                               |
| ----------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| [**Установщик Windows x64**](https://github.com/WAKUDOdani/WakuShare/releases/download/v1.3.3/WakuShare-1.3.3-setup-x64.exe)  | Обычная установка приложения             |
| [**Portable Windows x64**](https://github.com/WAKUDOdani/WakuShare/releases/download/v1.3.3/WakuShare-1.3.3-portable-x64.exe) | Запуск без установки; обновление вручную |

## Что нового

- Карточка Telegram внизу боковой панели: пресеты и находки для монтажа.
- Один световой блик на кнопке Telegram в приветственном окне; учитывается уменьшение движения.

## Улучшения

- Увеличен переключатель «Все проекты / Этот проект» в «Проводнике», улучшен контраст и выровнена высота кнопки добавления папки.
- Портативная версия показывает подпись `v1.3.3 · Portable`; установленная - номер версии.

## Важно

Сохранены функции 1.3.2: автосинхронизация, импорт `.capshare` и экспорт `.wakushare`. Движок синхронизации не менялся.

<details>
<summary>Совместимость и технические подробности</summary>

Целевая проверенная версия: **CapCut International Windows 9.6.0.4097, x64**.

Среды запуска и модуль синхронизации включены в оба EXE. В этой версии используется прежний базовый runtime, закреплённый в runtime-lock.json.

Для запуска нужен один EXE. `Source code` содержит исходники; `latest.yml`, `.blockmap` и runtime-архивы не нужно скачивать для обычной работы. Контрольные суммы - в `SHA256SUMS.txt` раздела Assets.

</details>
