# WakuShare 1.3.5 - Русский язык по умолчанию

<summary><strong>English release notes</strong></summary>

### WakuShare 1.3.5 - Russian by default

Both the installer and Portable editions now start in Russian on first launch.

### Download

| Edition                                                                                                                       | Purpose                         |
| ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| [**Windows x64 installer**](https://github.com/WAKUDOdani/WakuShare/releases/download/v1.3.5/WakuShare-1.3.5-setup-x64.exe)   | Regular app installation        |
| [**Windows x64 Portable**](https://github.com/WAKUDOdani/WakuShare/releases/download/v1.3.5/WakuShare-1.3.5-portable-x64.exe) | No installation; manual updates |

### Fixed

- New profiles and older settings without a language preference default to Russian in both editions.
- The interface also starts in Russian while settings load.
- A saved English or Russian choice is preserved across launches and updates. Switch languages in **Настройки → Внешний вид → Язык интерфейса** (**Settings → Appearance → Interface language**).

### Compatibility and technical details

Tested target: **CapCut International Windows 9.6.0.4097, x64**. This update changes the default interface language; project transfer, preset transfer, and the sync runtime are unchanged.

230 automated tests, TypeScript, ESLint, and local package verification passed. The user accepted the change. Builds remain unsigned. You only need one EXE; checksums are in `SHA256SUMS.txt`. `Source code` is for developers; `latest.yml` and `.blockmap` serve the updater.

## Исправления

- Новые профили и прежние настройки без выбранного языка используют русский в обеих версиях приложения.
- Начальная загрузка интерфейса тоже использует русский.
- Сохранённый выбор английского или русского остаётся при перезапусках и обновлениях. Переключатель доступен в **Настройки → Внешний вид → Язык интерфейса**.
