<summary><strong>English release notes</strong></summary>

### WakuShare 1.1.0 - The first WakuShare release

An independent CapShare fork for moving and backing up CapCut projects.

> [!NOTE]
> Archived release. For a regular installation, choose the [latest WakuShare version](https://github.com/WAKUDOdani/WakuShare/releases/latest).

### Download

| Edition                                                                                                                       | Purpose                         |
| ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| [**Windows x64 installer**](https://github.com/WAKUDOdani/WakuShare/releases/download/v1.1.0/WakuShare-1.1.0-setup-x64.exe)   | Regular app installation        |
| [**Windows x64 Portable**](https://github.com/WAKUDOdani/WakuShare/releases/download/v1.1.0/WakuShare-1.1.0-portable-x64.exe) | No installation; manual updates |

### What's new

- Consistent transfer of multiple timelines, their identifiers, folders, and layout.
- Source file collection from additional timelines and nested compositions. User media is placed under `Resources/local/Исходники` with working references.
- Size, SHA-256, and independent-copy checks. A dedicated WakuShare update channel and Telegram link.

### Important

The first release is based on CapShare 1.0.2 by Ilyasse Salama. The upstream history and MIT license are preserved. Settings and the update display were refined further in 1.1.1.

### Compatibility and technical details

Tested target: **CapCut International Windows 9.6.0.4097, x64**.

Tested with CapCut International Windows 9.6.0.4097. Installation and launch of this release were confirmed by the user. Builds do not have a Windows publisher signature.

You only need one EXE. `Source code` contains the source; `latest.yml`, `.blockmap`, and runtime archives are not needed for normal use. Checksums are in `SHA256SUMS.txt` under Assets.

## Что нового

- Согласованный перенос нескольких временных шкал, их идентификаторов, каталогов и раскладки.
- Сбор исходников из дополнительных шкал и вложенных композиций. Размещение пользовательских медиа в `Resources/local/Исходники` с рабочими ссылками.
- Проверка размеров, SHA-256 и самостоятельности новой копии. Собственный канал обновлений WakuShare и ссылка на Telegram.

## Важно

Первый выпуск на основе CapShare 1.0.2 от Ilyasse Salama. Сохранены история upstream и MIT-лицензия. Настройки и отображение обновлений дополнительно доработаны в 1.1.1.
