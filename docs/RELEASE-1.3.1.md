# WakuShare 1.3.1 - архив подготовки

> Отдельный публичный релиз 1.3.1 не выпускался. Функции ниже вошли в [WakuShare 1.3.2](https://github.com/WAKUDOdani/WakuShare/releases/tag/v1.3.2). Это исторический документ, а не ссылка на доступную сборку.

- Новый раздел «Проводник»: автоматическое добавление медиа из выбранных папок
  Windows в новые и существующие проекты CapCut с сохранением вложенности.
- Синхронизация по событиям, один список для массового импорта и понятный прогресс.
  Переименование и перенос источников сохраняют привязки материалов.
- Экспорт проектов в `.wakushare`; старые `.capshare` по-прежнему импортируются.
- Обновлённые пресеты: ровные отступы, понятная навигация и выбор, мягкое
  стеклянное наведение без фиолетовых рамок. Тёмные кнопки лучше видны поверх
  прозрачного окна, светлые сохраняют яркость при наведении.
- Номер версии под названием приложения. Уточнены подписи импорта.
- Модуль синхронизации и среды запуска включены в Windows-сборку.

Проверено на **CapCut International Windows 9.6.0.4097, x64**.
